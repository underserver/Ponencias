## jShop v1.0

### Introduction
jShop is a PHP-based online store solution designed to facilitate virtual shopping. Built by Sergio Ceron Figueroa (alias: sxceron), this project includes fundamental e-commerce features such as product browsing, user login, and registration.

### Key Features
- Products that are expired or out of stock are hidden and cannot be purchased if displayed.
- These changes are implemented in the index, search, and category sections.

### Installation
1. Clone the repository from GitHub: `git clone https://github.com/underserver/Ponencias.git`
2. Set up your MySQL database using the details in `includes/config.php`.
3. Start a local server and navigate to the project's root directory.

### Usage
- Users can browse products, register, and login to purchase items.
- Admins can manage product listings and verify user registrations.
