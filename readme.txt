Setup Instructions

Prerequisites:
1. PHP installed on your server (version 5.6 or higher is recommended).
2. MySQL server (version 5.7 or higher is recommended), and make sure the service is running.
3. Web server software like Apache or Nginx.

Installation Steps:
1. Clone or download the repository from GitHub: `git clone https://github.com/underserver/Ponencias.git`.
2. Place the downloaded project on your web server's root directory or a subdirectory.

Configuration:
1. Navigate to the `install` directory in your browser: `http://<your-server>/install/index.php`.
2. Follow the instructions to provide database credentials:
   - Database Name
   - Database User
   - Database Password
   - Database Host
3. Complete the installation process. If any step fails, please ensure that your database credentials are correct and that the MySQL service is running.

Post-Setup:
1. Delete the `install` directory to secure your installation after setup is complete.
2. Access the application by navigating to the URL: `http://<your-server>/index.php`.

Note:
For troubleshooting, refer to error logs available on your server and ensure that file permissions are correctly set for your web server to read the application files.
