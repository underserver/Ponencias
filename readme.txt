# Ponencias Project

## Overview
The Ponencias project is aimed at providing a platform for the management and evaluation of academic presentations known as 'ponencias'. It facilitates the registration of users with different roles such as administrators, presenters, and evaluators. The project supports the evaluation cycle of 'ponencias', enabling their review and status updates.

## Features
- Registration of users with distinct roles (Administrator, Presenter, Evaluator, etc.)
- Submission and status management of presentations ('ponencias')
- Assignment and management of evaluators for each 'ponencia'
- Evaluation process with scoring and observations
- Listing and retrieval of presentations and user data

## Key Changes
- Products that have expired or are out of stock are not displayed, and if they are, they cannot be purchased. These changes are applied to:
  - Index page
  - Search functionality
  - Category-based listings

## Installation
1. Clone the repository.
2. Set up the database configuration in `includes/config.php`.
3. Ensure dependencies are in place by including required libraries.
