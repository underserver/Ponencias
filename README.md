# Ponencias

Ponencias is a virtual store implemented in PHP by Sergio Ceron Figueroa. It offers various functionalities related to the management and presentation of conferences or presentations.

## Features

- User registration for different roles such as Speaker, Co-author, Attendee, and Evaluator.
- Administrator control panel for managing presentations.
- Presentation submission and management system.
- Login and registration system.
- Secure sessions and user authentication.
- Multilingual support with i18n.

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/underserver/Ponencias.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Ponencias
   ```
3. Set up your database with the `includes/db.php` configuration.
4. Ensure your server environment supports PHP.

## Usage

- Navigate to the project URL to view the homepage.
- Register new users under different roles.
- Administer presentations and user roles through the panel.

## Configuration

- Configure database settings in `includes/config.php`.
- Setup internationalization strings in `includes/i18n/`.
