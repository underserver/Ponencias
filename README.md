# Ponencias Project

## Overview

Ponencias is a PHP-based system for managing conference presentations. The application provides functionalities for users to register, submit presentations, and manage evaluation by reviewers.

## Features

- **User Registration**: Supports registration for different roles such as Speaker, Co-Author, Evaluator, and Attendee.
- **Presentation Submission**: Allows users to submit their presentations with relevant details like title, summary, and thematic area.
- **Evaluation Management**: Enables evaluators to rate and provide feedback on presentations.
- **Administrative Tools**: Features for administrators to oversee the conference submissions and user management.

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/underserver/Ponencias.git
   ```

2. Navigate to the project directory:
   ```bash
   cd Ponencias
   ```

3. Make sure your PHP environment is configured correctly, and all dependencies are installed.

4. Navigate to the `install` directory and follow the setup instructions:
   ```bash
   cd install
   ```

## Configuration

- Database configuration can be updated in the `includes/config.php` file.
- Additional setup might be necessary for the database, which is outlined in the installation guide available in the `install` directory.

## Usage

1. Access the application via a web browser:
   ```
   http://localhost/Ponencias/index.php
   ```

2. Register as a user to start submitting presentations or reviewing them, depending on your role.
